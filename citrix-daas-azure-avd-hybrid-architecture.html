Combining Citrix DaaS with Azure Virtual Desktop (AVD)

Integrating Citrix DaaS with Azure Virtual Desktop (AVD) brings together Microsoft's multi-session Windows 11 licensing entitlements and native Azure integration with Citrix's enterprise-grade HDX display protocol, advanced workspace policy controls, and multi-cloud management capabilities.

Architectural Synergy: Citrix DaaS acts as the high-performance control plane managing AVD session hosts across Azure regions, providing seamless user roaming between on-premises Citrix Virtual Apps and Desktops and Azure cloud workloads.

Azure Machine Creation Services (MCS) Image Pipeline

Provisioning ephemeral session host VMs at scale requires automated image management. Using Citrix Machine Creation Services (MCS) with Azure Compute Gallery (SIG), golden images are replicated globally across Azure regions for rapid catalog scaling.

1. Golden Master VM

Configured in Azure with Windows 11 Enterprise Multi-Session, Microsoft 365 Apps for Enterprise, Citrix VDA 2407+, and FSLogix agent.

2. Azure Compute Gallery

Replicates master image disk snapshots across multiple target Azure regions and Availability Zones for instant VM provisioning.

3. Ephemeral OS Disks

Utilizes Azure Ephemeral OS Disks (located directly on hypervisor host local NVMe) to achieve zero storage transaction costs and near-instant boot times.

4. MCSIO Caching

Configures RAM-based write-caching with disk overflow (`MCSIO`), reducing disk IOPS cost by up to 85% during morning logon storms.

Optimizing FSLogix Profiles on Azure Storage

  1. Storage Platform Selection: Deploy Azure NetApp Files (ANF) or Azure Premium Files with SMB Multichannel for sub-millisecond IOPS performance during login spikes.
  2. VHD Location Redundancy: Implement FSLogix Cloud Cache (`CCDLocations`) to asynchronously mirror VHDX profiles between primary Azure regions and secondary disaster recovery regions.
  3. HDX Protocol Optimization: Enable Citrix Adaptive Transport (EDT over UDP) alongside AV1/H.264 hardware encoding to deliver smooth 60 FPS video performance over high-latency networks.
