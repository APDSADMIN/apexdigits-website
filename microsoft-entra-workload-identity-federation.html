Microsoft Entra Workload Identity Federation: Eliminating Secrets in Multi-Cloud GitHub Actions & AWS EKS Pipelines

How enterprise DevOps teams use OpenID Connect (OIDC) federation to exchange short-lived JWT tokens for Entra access tokens without storing service principal secrets.

Gunas
Principal Cloud & AI Security Architect

The Danger of Hardcoded Service Principal Secrets

Storing long-lived client secrets and passwords inside GitHub Secrets, AWS Secrets Manager, or CI/CD environment variables is a major source of security leaks. **Microsoft Entra Workload Identity Federation** leverages OpenID Connect (OIDC) to establish trust between GitHub Actions, Kubernetes pods, or AWS IAM roles and Microsoft Entra ID.

Architecture Overview: OIDC Token Exchange Sequence

Figure 1: Cryptographic JWT Exchange between GitHub Actions and Microsoft Entra ID

1. GitHub Actions OIDC Provider

Issues a signed JSON Web Token (JWT) containing `iss`, `sub`, and `aud` claims specific to the running GitHub repository and branch.

2. Federated Identity Credential

Configured on the Entra App Registration to match the exact Subject Claim (`repo:org/repo:ref:refs/heads/main`).

3. Entra STS Token Issue

Validates the GitHub OIDC signature and issues a short-lived (1-hour) Entra Access Token with scoped Azure RBAC permissions.

4. Zero Storage Overhead

Eliminates secret rotation tasks, password expiration outages, and credential leak risks permanently.

GitHub Actions Workflow: Passwordless Azure Deployment

name: Deploy Azure Infrastructure

on:
  push:
    branches: [ main ]

permissions:
  id-token: write # Required for requesting OIDC JWT token
  contents: read

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Azure Login via OIDC Federation
        uses: azure/login@v2
        with:
          client-id: ${{ secrets.AZURE_CLIENT_ID }}
          tenant-id: ${{ secrets.AZURE_TENANT_ID }}
          subscription-id: ${{ secrets.AZURE_SUBSCRIPTION_ID }}

      - name: Run Azure CLI Commands
        run: |
          az account show
          az group list --output table
